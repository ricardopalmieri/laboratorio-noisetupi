# NT Zine Editor

Editor de fanzines em arquivo único (`zine-editor.html`), com camadas, recorte de imagem, imposição para impressão (caderno com dobra e grampo, zine de 8 páginas, leitura 2-up) e exportação em PDF, inclusive PDF imposto em A4. Visão geral em [`docs/plataforma.md`](../../docs/plataforma.md#nt-zine-editor).

- `zine-editor.html`: aplicação completa, com HTML, CSS e JavaScript inline
- `.htaccess`: HTTPS, cabeçalhos de segurança e Content-Security-Policy
- `thumb.png`: miniatura

Para publicar com URL limpa, publique `zine-editor.html` também como `index.html`.
